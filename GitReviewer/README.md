# Git Reviewer

Windows-приложение на .NET 10 для проверки новых Git-коммитов с помощью
локальной или облачной OpenAI-совместимой модели.

## Запуск

Требования:

- Windows 10 или Windows 11;
- .NET 10 SDK для сборки;
- установленный Git;
- локальная модель либо API-ключ облачного сервиса.

Сборка и запуск:

```powershell
dotnet build
dotnet run
```

После запуска выберите Git-репозиторий, настройте профиль модели, проверьте
подключение и нажмите `Старт`. При первом подключении проверяется текущий
`HEAD`, но не более ранние коммиты. Затем приложение выполняет
`git pull --ff-only` и проверяет каждый новый коммит отдельно.

Закрытие окна или его сворачивание скрывает интерфейс в системный трей.
Проверка продолжает работать. Для полного завершения выберите `Выход` в меню
значка трея.

## Локальные файлы

Пользовательские данные хранятся в `%LOCALAPPDATA%\GitReviewer`:

```text
models.conf
settings.conf
system-prompt.txt
state.json
reports\
```

Настоящие ключи не должны добавляться в Git. В репозитории хранится только
безопасный `models.example.conf`. Значение из `api_key_environment` имеет
приоритет над `api_key`.

Системный промпт и профили моделей можно изменять в GUI. Ответ модели имеет
простой текстовый формат `BUG ... END` или `NO_BUGS`; генерировать JSON от
модели не требуется.

Интерфейс переключается между English и Russian на вкладке проекта. Если
системный промпт не был изменен пользователем, язык стандартного промпта также
переключается автоматически.

Поле `Review selected commit` позволяет проверить конкретный короткий или
полный SHA. Такая ручная проверка добавляется в отчет, но не изменяет позицию
автоматического наблюдения в `state.json`.
